Engine Architecture v6

How guardFunc, declarative-spec base resolution, and 3D spatial execution collaborate inside the runner pipeline.

1. The v6 Execution Loop: runInstructions

In `v6`, the runner orchestrates validation, base resolution, and step execution seamlessly: 

const runInstructions = (inConfig = {}) => {
    guardFunc(inConfig);

    const {
        instructions = [],
        baseKey,
        data,
        showLog = false
    } = inConfig;

    const base = spec[baseKey];

    instructions.forEach(key => {
        if (showLog) console.log(`[runStep] ${key}`);
        executeStep(key, { base, data }, showLog);
    });

    return base;
};
1
Pre-Flight Guard Verification:

guardFunc asserts config shape, ensures baseKey exists in declarative-spec, and validates the instructions array.

2
Base Canvas Resolution:

Fetches spec[baseKey] directly from declarative-spec without manual deep cloning by the caller.

3
Step Iteration via executeStep:

Each instruction key is dispatched to its 0D, 1D, or 2D transformer and written in place.

4
Global Registration:

Automatically exposed to window.ks.jsonRenderers.runInstructions.steps for seamless script-tag and CDN consumption.

2. The 4-Line executeStep Core

export const executeStep = (key, state, showLog = false) => {
    const instruction = instructions[key];
    const result = types[instruction.type](instruction, state);
    writeResult(state, instruction.destinationPath, result, showLog);
    return result;
};
