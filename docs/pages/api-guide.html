Documentation & Reference

API Guide & Reference

Complete specifications for runInstructions, guardFunc, executeStep, and global registration.

runInstructions(inConfig)

Default Export

Validates the config object with guardFunc, resolves the base canvas AST from declarative-spec[baseKey], and executes each instruction key sequentially.

Signature
runInstructions(inConfig: {
    baseKey: string,
    instructions: string[],
    data: { columns?: any[], data?: any[], [key: string]: any },
    showLog?: boolean
}): object
Parameters (inConfig)
Parameter Type Required Description
baseKey string Yes Non-empty string matching an existing key in declarative-spec (e.g. "tableSimple", "selectBase", "dataListSimple", "formSimple").
instructions string[] Yes Non-empty array of non-empty strings matching blueprint keys in declarative-instructions.
data object Yes Data payload containing columns array and/or data rows array.
showLog boolean No When set to true, outputs debugging info for each step. Default: false.
Return Value

Returns the mutated base specification object containing the complete AST with all generated children and attributes.

guardFunc(inConfig)

Named Export

Validates the input configuration before execution begins. Throws meaningful TypeError or Error if inputs are invalid.

  • Throws TypeError("Config must be an object") if inConfig is not a valid non-array object.
  • Throws TypeError("baseKey must be a non-empty string") if baseKey is invalid.
  • Throws Error('baseKey "..." does not exist in declarative-spec') if the key is missing from the spec repo.
  • Throws TypeError("instructions must be an Array") or Error("instructions cannot be empty").
  • Asserts each instruction entry is a non-empty string.

executeStep(key, state, showLog)

Named Export

Executes a single instruction step against a state context { base, data }. 

executeStep(key: string, state: { base: object, data: object }, showLog?: boolean): any

Browser Global Registration

When using the distributed bundle (`docs/dist/v6/min.js`), the runner is automatically attached to: 

window.ks.jsonRenderers.runInstructions.steps = {
    meta: { name: "json-renderers-run-instructions", version: "1.6.1" },
    runInstructions: Function
};
