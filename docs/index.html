Engine Sequential Blueprint Step Runner

Sequential Blueprint Step Runner for Declarative Renderers

Executes declarative instructions step-by-step on canvas specifications using 3D spatial transformers. Lightweight, deterministic, and 100% zero-DOM.

Usage

Minimal & Agnostic

One simple function call executes entire multi-step UI blueprint pipelines without manual loop construction or DOM dependencies.

Open Playground npm Package 
import runInstructions from "json-renderers-run-instructions-steps";

const spec = runInstructions({
    baseKey: "tableSimple",
    instructions: [
        "buildColgroup",  // 1D: columns -> <colgroup><col>
        "buildHeader",    // 1D: columns -> <thead><th>
        "buildBody"       // 2D: rows x columns -> <tbody><tr><td>
    ],
    data: { columns, data }
});
