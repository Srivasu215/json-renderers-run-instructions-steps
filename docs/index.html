Architectural Foundation

Tri-Dimensional Delegation Framework

Zero loops inside the engine. The runner acts as a pure coordinator, delegating data transformation directly to specialized mathematical dimension handlers.

0D Dimension

Primitive Interpolation

Maps single scalar values, objects, or containers into declarative node templates. Ideal for cards, badges, and layout wrappers.

applyTemplate(source, template)
  • Powered by json-transformer-funcs-primitive
  • Evaluates property tokens and expressions
  • Generates single structural shells
1D Dimension

Linear Collection

Projects a 1-dimensional array across an instruction template. Builds sequential siblings like colgroups, table headers, and list items.

fromCollection(items, template)
  • Powered by json-transformer-funcs-one-dimension
  • Iterates linear collections with column mappings
  • Creates <col> and <th> specs
2D Dimension

Cartesian Matrix

Computes cross-product coordinates across rows and columns. Constructs complex 2D data grids, selects, and nested option sets.

rowOnColumn / columnOnRow
  • Powered by json-transformer-funcs-two-dimensions
  • Merges column specifications with data row keys
  • Handles <tbody>, <tr>, and <td>
Developer Experience

Simple, Clean, and Agnostic

Whether you are rendering a data table, an interactive select box, a datalist auto-complete, or dynamic input form fields, the runner API remains completely uniform:

Deterministic Execution:

Runs identical instruction sequences across browsers and backend server runtimes.

Decoupled Blueprints:

Instructions live independently in declarative-instructions and can be shared across any renderer.

In-Place Tree Writing:

Powered by jsonpathly and json-write-path for blazing-fast tree assembly without GC spikes.

import runInstructions, { executeStep } from "json-renderers-run-instructions-steps";
import { spec } from "spec-repo";

// 1. Initialize clean base canvas template
const base = structuredClone(spec.tableSimple);

// 2. Execute blueprint instructions sequentially
const resultSpec = runInstructions({
    instructions: [
        "buildColgroup",  // 1D: maps columns to <colgroup><col>
        "buildHeader",    // 1D: maps columns to <thead><th>
        "buildBody"       // 2D: maps rows x columns to <tbody><tr><td>
    ],
    base,
    data: {
        columns: [
            { key: "id", label: "ID" },
            { key: "name", label: "Name" }
        ],
        data: [
            { id: "101", name: "Alpha" },
            { id: "102", name: "Beta" }
        ]
    },
    showLog: true
});

console.log("Rendered JSON UI Spec:", resultSpec);
